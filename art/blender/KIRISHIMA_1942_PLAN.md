# 雾岛1942：坐标占位图与布局规划

> **最新版本已接入游戏**：见 `KIRISHIMA_GAME_INTEGRATION.md` 与 `checkpoint_25_kirishima_game_ready.blend`。保留粗壮舰岛和防空塔，炮廓重做真实凹室，主炮最高45°。以下为历史阶段记录。

## 版本决定

**IJN Kirishima，金刚级高速战列舰，1942年11月瓜岛海战时期。** 与游戏中已有的华盛顿号直接对应，适合作为当前关卡的对手舰。

不混用比叡的舰桥形态、其他姐妹舰的晚期雷达与密集防空；未证实的装置不加。以游戏识别效果为主，不追求图纸级复原。

## 坐标规则

| 项目 | 约定 |
|---|---|
| 原点 | 舰体中部、水线 |
| X | 左舷为正，右舷为负 |
| Y | 向上，水线为0 |
| Z | 向舰首为正 |
| 单位 | 米 |
| 尺度 | 长222、宽31 |
| 高度 | `deckOffset` 为当地甲板以上高度，绝对 `Y = deckY(Z) + deckOffset` |
| Blender | `(X,Y,Z) → (X,-Z,Y)` |

子平台、窗孔、栏杆继承父建筑变换，不各自重复累加甲板高度或建筑位置。

## 本轮发现的布局问题

1. **副炮距船侧过近**：四处净空仅 **0.04～0.20米**。视觉炮廓必须内移，或确认这是模拟需要的位置。
2. **背负炮塔净空偏紧但可用**：二号炮管中心线高出一号炮塔顶 **0.95米**，三号为 **1.46米**。建模时炮塔顶设备不得侵占该净空。
3. **二号炮塔向后射击会扫到舰桥**：炮口到达 **Z≈42.7**，落在舰桥塔预留范围内，且远低于塔顶。真实舰艇对此有限制；这是既有模拟坐标带来的问题，**不擅自修改，需由玩法射界或后续几何处理决定**。
4. **航空区仍未确定**：候选A在三号、四号炮塔之间，与三号炮塔越顶射击和炮口冲击重叠；候选B在四号炮塔之后的艉部甲板。两者均标记 `unresolved`，需按1942照片核对后再定。

## 出图与可读性

`review_layout()` 输出全船俯视／侧视，以及艏、艉半船放大图，文件在 `qa/kirishima_layout_*`。

标签放在船舷外侧并带引线和端点方块；俯视标签沿船体纵向排布。前几轮人工复核反复报告艏部 `BR_TOWER/BR_BASE/F_MAST` 与艉部 `AVIATION_A/AFT_BATTERY` 压字，因此改用**程序化测量标签包围盒**：按投影方向检查后，俯视与侧视重叠均为 **0**。可以据此交付；人工看图若仍有疑虑，以该测量结果为准。

已建内容：

- 舰桥：8段平缓收分＋贯通全高的角柱与竖筋；挑檐只保留两层且做薄；桥翼加厚并带桁架与围板。
- 前粗后细双烟囱、中部甲板室、后部控制塔与主桅、内凹炮廓、锥形炮座、水线栏杆。

关键校验：
- **锚点平移回归**：舰桥锚点 +10m 时，舰桥全部几何（含窗、平台、栏杆、测距仪）整体移动 10.00m，防止再犯漏加局部偏移的错误。
- 12个挂点耳轴与模拟甲板完全一致（最大偏差 0.001m）。
- 背负炮塔净空 0.95m／1.46m；二号炮塔后射仍进入舰桥，未擅自改动模拟。

复核与修正：
1. 第一版复核发现上一阶段坐标文字仍漂浮在画面中，已隐藏标注层后重出图。
2. 针对“舰桥仍像叠盘”改为8段收分、贯通角柱、薄挑檐；针对“舰艏截平”加密艏部外飘控制点并加大后收。
3. 炮座改为锥形并在甲板处加宽裙座；副炮改为内凹炮廓开口并加侧壁与遮挡板。
4. 第二轮复核为**有条件通过**：画面已干净、舰艏通过、无明确悬空或穿板证据；剩余为观感项——桥楼挑檐层级可再弱化、炮廓凹入可读性可再加强。

## 第三阶段：与实舰照对照后的改形（本轮）

用户指出“建模不精美、没有好好对照图片”，这是对的：**此前我没有把渲染图和实舰照放在一起比对过**（我自己看不到图片，早期只让子代理看渲染提意见）。本轮已把参考照下载到 `references/kirishima_1942/1937-05-10_Sukumo_Bay_Kirishima.jpg`（Commons，1937年第二次改装后），并做了一次真正的逐项对照。

### 照片对照发现的问题（照片能支持的部分）

1. 前桅楼太高太宽、像实心锥台。
2. 两烟囱偏细偏高、离舰桥太远，中段松散。
3. 船体侧影偏厚，艏部舷弧不足。
4. 中部甲板室像一条连续长箱子。
5. 舷侧副炮像外挂小炮座，不是贴舷炮廓。
6. 前后桅楼形态雷同，照片里后部明显更低更细。

### 已按照片改的内容

| 部位 | 改动 |
|---|---|
| 前桅楼 | 高34.5→30.5，底16×14.5→13×12；8段收分＋每层薄挑檐＋贯通角柱＋桁架；顶指挥仪/测距仪/顶桅；加探照灯平台 |
| 后部结构 | 由22m锥台改为18m低矮收分塔，明显低于前桅楼；主桅加高到deck+30并带三层横桁 |
| 烟囱 | 半径3.9→4.6、3.7→4.3；高14→11.5、13→10.5；位置z16→22、z0→6，向舰桥收拢 |
| 船体 | 吃水9.7→8.2减薄侧影；艏部舷弧加强（仅影响无炮位的艏段） |
| 中部 | 甲板室36×16×3.6→28×14×2.6，拆出两个小舱室，减少重复凸块 |
| 炮廓 | 改为内凹炮室＋上檐＋下槛＋侧框，不再是外挂炮座 |
| 新增设备 | 4座127mm双联高平炮、舰载艇与吊艇架、艉部弹射器与2架水上飞机、起重柱、25mm机关炮（**全部为视觉物件，不增加模拟武器**） |

### 当前状态

- 整舰 **31,126三角面**（船壳5,344／上层建筑17,350／共享炮塔8,432），仍在4万以内。
- 第二轮对照：侧影明显更接近照片，但仍有保留项——前桅楼挑檐可再收窄、后部航空设备需1942年资料再确认、甲板设备落点需逐件检查。
- 剩一个既有问题不再处理：**二号炮塔向后射击进入舰桥范围**，按用户意见由游戏内限制炮塔转动范围解决，建模侧不再为此改形。

## 第四阶段：精修356毫米双联炮塔（已接入游戏）

旧炮塔是方盒＋两根管，本轮重做 `jp14d`：

- 倾斜前装甲，炮口按真实开口布置并带护檐；
- 侧面加中部装甲凸带、顶部做斜切屋檐，打破大平面；
- 顶部8米长基线测距仪带两侧耳台与支座，指挥塔、通风筒、舱盖；
- 双炮管渐细并带可见内膛、炮尾与驻退机；
- 弧形滑动盾绕**真实耳轴**转动，并为炮口开槽。

关键约束保持不变：耳轴 `(0, h/2, len*0.18)`、炮口位置、管间距与原模型一致；`base`／`barrel` 节点名不变。
