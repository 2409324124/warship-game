# USS Washington (BB-56) 历史照片参考

核验日期：2026-10-21。范围：1942 年瓜岛时期 BB-56 舰岛精修用历史参考。共下载 5 张不同照片，其中 **3 张有无矛盾的 1942 年具体日期**，另 1 张属于 1942 年但具体日期有疑问，1 张是明确标注的 1941 年辅助照片。没有现代博物馆照片。

全部用 webfetch 检查 Commons 原始 File 页的说明、日期、作者和授权；以 curl.exe 下载，下载前 Test-Path 确认目录。5 张均已用 read 实际打开：均可解码为历史黑白舰船照片，图像形态与来源所指 BB-56 相符。身份依靠档案/照片说明确认，不声称仅靠同级舰外观即可独立辨明舰名。第 5 张还有底片上的 Washington 手写题注。

## 对模型对照可直接提出的核查点

1. 第 1 张证明 1942-08-18 已存在塔正面的 SG 安装位置；精修时须对照这一位置，而非仅在最高处泛放一个雷达。
2. 第 1、2 张共同展示“下层舰桥体块—高塔柱—多层外挑平台—测距仪与网格天线”的垂直层级，可检查模型有无把它简化成均匀圆柱/单一方盒。此为检查项目，本任务未打开模型，不能宣称模型已经存在这些错误。
3. 1941 年辅助照与 1942 年 8 月近照的顶部天线外观确有差别；不得把 1941 年顶部轮廓未经核对直接用于瓜岛时期。
4. 第 3、4 张逆光/海况遮挡明显；“看不见”不等于设备不存在。

## 资料边界

- 本组选片已满足至少 3 张真正 1942 年实舰照片；只有第 1、2 张是 1942 年 8 月赴太平洋前后近期参考，**没有把它们冒称为 11 月瓜岛现场照片**。
- 找到的清晰 1942 年斜前航空照为右舷；本组左舷斜前照是 1941 年辅助。没有找到并纳入同等清晰、有确切日期的 1942 年左舷斜前照，应如实保留这一视角缺口。
- 未下载 `USS Washington (BB-56) a.jpg` / `USS Washington (BB-56).jpg`：File 页分别称战争后期/1944，不能作 1942 年主体证据。也未下载 BS33802：本次检查的 File 页无明确拍摄日期，不能仅凭相邻底片号赋予 1942-08-21。
